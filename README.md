\# 🎓 GradeCap



GradeCap is an all-in-one academic companion built with Flutter.

It helps students manage grades, track attendance, plan exams, and stay organized throughout the semester — all in one simple app.



\## ✨ Key Features

\- 📊 \*\*CGPA \& SGPA Calculator\*\* – Semester-wise and overall CGPA tracking

\- 🗓 \*\*Attendance Tracker\*\* – Monitor subject-wise attendance and stay exam-eligible

\- 📝 \*\*Exam Planner\*\* – Plan upcoming exams, tests, and deadlines

\- 📚 \*\*Subject Management\*\* – Organize subjects semester-wise

\- 🌙 \*\*Dark Mode\*\* – Clean and eye-friendly interface

\- ⚡ \*\*Offline Support\*\* – Works completely without internet

\- 🎯 \*\*Student-Focused UI\*\* – Minimal, distraction-free design

\- 🚀 \*\*Fast \& Lightweight\*\* – Optimized for smooth performance



\## 🛠 Tech Stack

\- Flutter

\- Dart
